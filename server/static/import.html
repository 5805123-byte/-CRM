📥 ייבוא רשימת מגבית

מדביקים כאן את הרשימה מהאקסל (שם + סכום), המערכת מתאימה כל שורה לתורם הקיים ולחיוב שטרם אושר — ומכניסה את התרומה עם התאריך ואמצעי התשלום האמיתיים מהחיוב. קודם בודקים, אחר כך מכניסים. מי שלא זוהה נשאר לך לטיפול ידני.
מזהה גם פסיקים וגם טאבים. אפשר להשאיר כותרות — הן מזוהות ומדולגות. עמודה שלישית, אם יש, נשמרת כהערה.
