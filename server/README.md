# מערכת כולל חצות — אפליקציה אמיתית (שרת + בסיס נתונים)

זו הגרסה ה"אמיתית": ממשק שאפשר **לערוך בו ישירות והכל נשמר** בבסיס נתונים (SQLite).
לא צריך להעתיק/להדביק — עורכים בכרטיס, וזה נשמר מיד.

## מה יש בה
- **תורמים** — עריכה חיה של קטגוריה, מטרה, סכום, טלפון, אימייל, כתובת.
- **התחייבויות / קמפיינים** — לכל תורם: מוסיפים סכום + קטגוריה (למשל "חגי סוכות").
  מי שעדיין לא נתן = **אדום**; נתן = **ירוק**. כפתור אחד מעביר ביניהם.
- **קמפיינים** — סיכום לכל קמפיין: כמה נתנו, כמה טרם, סכום שהתקבל מול צפוי.
- **פרנס יום** — הוספת לילה + הקדשה לכל תורם, ותצוגת לוח שנה שנתי.

## הפעלה (על מחשב עם Python)
```bash
cd server
python3 import_data.py     # טוען את הנתונים מ-starter/crm-donors-filled.xlsx לתוך crm.db
python3 app.py             # מריץ את השרת
```
פותחים בדפדפן: **http://localhost:8000**

הנתונים נשמרים בקובץ `server/crm.db`. אפשר לגבות אותו בהעתקה פשוטה.

## מבנה
```
server/
  app.py            — השרת (Python בלבד, ללא תלויות חיצוניות) + API לשמירה
  import_data.py    — טעינת הנתונים הנקיים מהאקסל ל-SQLite
  crm.db            — בסיס הנתונים (נוצר ע"י import_data; לא נשמר ב-git)
  static/
    index.html      — הממשק
    app.js          — לוגיקת הממשק (טעינה ושמירה דרך ה-API)
```

## הפעלה מרחוק / אירוח
כדי שתוכל להיכנס מכל מקום (לא רק מהמחשב המקומי), צריך לארח את השרת.
אפשרויות פשוטות: Render / Railway / PythonAnywhere (יש להם שכבת חינם).
צריך רק Python 3 — אין תלויות חיצוניות להרצת השרת.
