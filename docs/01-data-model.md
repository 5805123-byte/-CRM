# מה שומרים על כל דבר

המערכת בנויה מ-4 "כרטיסים" מחוברים: **תורם**, **תרומה**, **שם לתפילה**, ו**קוויטל**.
תורם אחד יכול להיות מחובר להרבה תרומות, והרבה שמות לתפילה.

```
תורם ──┬── תרומות (כל תרומה בנפרד)
       ├── שמות לתפילה (על מי מתפללים ולמה)
       ├── היסטוריית קשר + תזכורות
       └── מקורות (מאיפה המידע הגיע)
```

---

## תורם

הכרטיס המרכזי — כל מה שיודעים על אדם או עסק.

- **שמות**: שם פרטי עברי, שם משפחה עברי, שם באנגלית, ושם עסק (כשהתרומה מגיעה מהעסק).
- **פרטי קשר**: טלפונים, אימיילים, וואטסאפ, כתובת.
- **תאריכים חשובים**: יום הולדת, יארצייטים, ותאריכים שהוא רגיל לתרום בהם (מרשימת הוורד).
- **דרגת הקוויטל שלו**: יששכר-זבולון / קוויטל 101 / כללי / חד-פעמי.
- **תוויות**: בדיוק כמו התוויות שיש לך בגוגל תחת "קוויטל".
- **היסטוריית קשר**: מתי דיברת ועל מה (ראה למטה).
- **תזכורות**: לחזור אליו, ליום הולדת, לתאריך תרומה קבוע.

## תרומה

רשומה נפרדת לכל תרומה, כדי שתהיה היסטוריה מלאה.

- **כמה** ובאיזה מטבע, ו**מתי**.
- **ערוץ** — מאיפה הכסף הגיע (אתר / נדרים פלוס / בנק / וואטסאפ / מייל...).
- **סוג התרומה** — פרנס יום, פרנס המאור, שותפות יששכר-זבולון, כולל חצות כללי וכו'
  (הרשימה המלאה ב-[02](02-donation-types-and-kvittels.md)).
- **תדירות** — חד-פעמי / יומי / שבועי / חודשי / שנתי.
- **בשם מי** — האדם או העסק.
- **ייעוד** — למה נועדה התרומה.

## שם לתפילה

מה שהתורם מסר כדי שיתפללו עליו. זה מה שנכנס בסוף לקוויטל.

- **השמות** (למשל "פלוני בן פלונית").
- **הבקשה** — על מה מתפללים: רפואה, זיווג, זרע של קיימא, פרנסה, ישועה...
- **דרגת התפילה** — נגזרת מגובה/סוג התרומה (יששכר-זבולון / 101 / כללי / חד-פעמי).
- **לאילו קוויטלים (תוויות) הוא שייך**.
- **מתי נכנס** ועד מתי פעיל (למשל חד-פעמי — לתפילה אחת).

> כשתרומה חדשה מגיעה מהאתר עם שמות — היא נכנסת לכאן אוטומטית, עם תזכורת להתפלל בחצות.

## היסטוריית קשר (על כל תורם)

לכל מגע: **מתי** היה, באיזה **ערוץ** (טלפון / מייל / וואטסאפ), ו**מה נדון**.
המידע נשאב אוטומטית מהוואטסאפ והמייל, כדי שתמיד תדע מתי דיברת לאחרונה ועל מה.

## קוויטל

לא "כרטיס" אלא **רשימה מודפסת** שנבנית אוטומטית מהנתונים לפי סינון:
כל התורמים הקבועים, או רק קוויטל 101, או רשימה מיוחדת לנסיעה — עם אפשרות
להוסיף חד-פעמיים. פירוט מלא ב-[02](02-donation-types-and-kvittels.md).

## מקורות (למה זה שם)

כל פרט זוכר מאיפה הגיע — האקסל, אנשי הקשר בגוגל, רשימת הוורד, וואטסאפ או מייל —
כדי שנוכל למזג בבטחה בלי כפילויות, ותמיד לדעת מאיפה כל נתון בא.
