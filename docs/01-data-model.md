# מודל הנתונים המאוחד

המבנה בנוי סביב ישות מרכזית אחת — **תורם** — שאליה מקושרות שתי רשימות:
**תרומות** ו**אינטראקציות (היסטוריית קשר)**. כל רשומה שומרת גם את **המקור** שממנו
הגיעה, כדי שנוכל תמיד לעקוב אחורה ולמזג בביטחון.

```
תורם
 ├── זהות          — שמות עברית/אנגלית, שם עסק
 ├── פרטי_קשר      — טלפונים, אימיילים, וואטסאפ
 ├── תרומות[]      — רשומה לכל תרומה
 ├── אינטראקציות[] — היסטוריית קשר, רשומה לכל מגע
 └── מקורות[]      — מזהי מקור למיזוג ומעקב
```

| `שם_משפחה_עברי` | מחרוזת | **ממולא ידנית**. |

> מיון, חיפוש והתאמה מדויקים בלי לנחש איפה נגמר השם הפרטי.

## 2. תרומה

רשומה **לכל תרומה בנפרד**. כך נשמרת היסטוריה מלאה ואפשר לנתח לפי ערוץ, ייעוד ותאריך.

| שדה | טיפוס | הסבר |
|------|-------|------|
| `מזהה_תרומה` | מחרוזת | מזהה תרומה. |
| `מזהה_תורם` | מחרוזת | קישור לתורם. |
| `תאריך` | תאריך | תאריך התרומה. |
| `סכום` | מספר | סכום. |
| `מטבע` | מחרוזת | ברירת מחדל `USD`. |
| `ערוץ` | אחד מ | **הערוץ/אמצעי המדויק** — ראה רשימה למטה. |
| `ייעוד` | מחרוזת | **למה נועדה התרומה** (הקרן/המטרה). |
| `חוזרת` | בוליאני | תרומה חוזרת / הוראת קבע. |
| `בשם` | אחד מ | `אדם` / `עסק` — האם התרומה בשם האדם או העסק. |
| `מזהה_חיצוני` | מחרוזת | מזהה עסקה במקור (לזיהוי כפילויות). |
| `מקור` | מחרוזת | שם קובץ/מערכת המקור. |
| `גולמי` | אובייקט | הרשומה הגולמית המקורית (לשקיפות ובקרה). |

### ערוצי תרומה (`ערוץ`)

ערכים מוכרים (ניתן להרחיב): `אתר`, `בנק_ווסט`, `אותורייז`, `פידליטי`, `OJC`,
`דונורס_פאנד`, `צ'ק`, `מזומן`, `העברה_בנקאית`, `זל`, `פייפאל`, `אחר`.

## 3. אינטראקציה (היסטוריית קשר)

רשומה **לכל מגע**, מסונכרנת אוטומטית מהערוצים (טלפון, מייל, וואטסאפ).

| שדה | טיפוס | הסבר |
|------|-------|------|
| `מזהה_אינטראקציה` | מחרוזת | מזהה. |
| `מזהה_תורם` | מחרוזת | קישור לתורם. |
| `חותמת_זמן` | תאריך-שעה | **מתי** היה הקשר. |
| `ערוץ` | אחד מ | `טלפון` / `מייל` / `וואטסאפ` / `פנים_אל_פנים` / `סמס`. |
| `כיוון` | אחד מ | `נכנס` / `יוצא`. |
| `תמצית` | מחרוזת | **מה נדון** — תמצית השיחה/ההתכתבות. |
| `משתתפים` | מערך מחרוזות | מי היה מעורב (אם רלוונטי). |
| `מזהה_חיצוני` | מחרוזת | מזהה במקור (שרשור/שיחה) למניעת כפילויות בסנכרון. |
| `מקור` | מחרוזת | ממה נשאב (Gmail, וואטסאפ, יומן שיחות...). |

> **סנכרון אוטומטי:** האינטראקציות נכנסות אוטומטית מהערוצים. `מזהה_חיצוני` הוא
> המפתח שמונע כפילויות כשמסנכרנים שוב ושוב. את חיבורי הסנכרון בפועל
> (Gmail, וואטסאפ וכו') נגדיר בשלב נפרד — כאן מוגדר רק מבנה היעד שאליו הם כותבים.

## 4. מקור (מיזוג ומעקב)

לכל תורם רשימת `מקורות` — עקבות למקורות שממנו נבנה, כדי לאפשר מיזוג בטוח ומעקב.

| שדה | טיפוס | הסבר |
|------|-------|------|
| `מערכת` | אחד מ | `סיכום_תרומות` / `גוגל_קונטקטס` / `ידני` / (בעתיד `אברכים`). |
| `מזהה_במקור` | מחרוזת | המזהה של הרשומה במקור (למשל resourceName של Google, או מפתח שורה בסיכום). |
| `הותאם_לפי` | אחד מ | `שם_עברי_ידני` / `אימייל` / `טלפון` / `שם_מדויק`. |
| `רמת_ביטחון` | אחד מ | `מאושר` / `סביר` / `לא_מאומת`. |
| `קושר_בתאריך` | תאריך-שעה | מתי קושר. |

ההתאמה הראשית בין **Donations Summary** ל-**Google Contacts** מתבצעת דרך
`הותאם_לפי = שם_עברי_ידני` — כלומר השם העברי שמילאת ידנית בקובץ ה-Excel.
הפירוט המלא ב-[02-merge-and-matching.md](02-merge-and-matching.md).
