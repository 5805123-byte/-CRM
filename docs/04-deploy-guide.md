# העלאת האפליקציה לאוויר (אירוח ב-Render)

מדריך צעד-אחר-צעד להעלות את המערכת כך שתוכל להיכנס אליה מכל מקום, עם **שמירת נתונים קבועה**.

## מה שהוכן עבורך
- `render.yaml` — הגדרת האירוח (כולל דיסק קבוע לשמירת הנתונים).
- `server/start.py` — זורע את הנתונים בפעם הראשונה ומריץ את השרת.
- `requirements.txt` — התלות היחידה (openpyxl, לטעינה הראשונית).

## השלבים (כ-10 דקות)

1. **חשבון** — היכנס ל-[render.com](https://render.com) והירשם (אפשר עם Google).
2. **חיבור הריפו** — לחץ **New +** → **Blueprint**.
3. חבר את חשבון ה-GitHub שלך, ובחר את הריפו **`5805123-byte/-crm`**,
   ואת הענף **`claude/unified-crm-data-structure-c2tt91`**.
4. Render יזהה אוטומטית את `render.yaml` ויציג את השירות. לחץ **Apply**.
5. המתן ~2 דקות עד שהסטטוס **Live**. תקבל כתובת כמו
   `https://kollel-chatzot-crm.onrender.com` — זו האפליקציה שלך, חיה.
6. פתח את הכתובת → כל הנתונים שם, ואפשר לערוך והכל נשמר. 🎉

## עלות — חשוב לדעת
כדי שהנתונים **יישמרו לתמיד** (גם אחרי עדכונים) צריך דיסק קבוע, שדורש תוכנית
בתשלום — בערך **$7 לחודש**. זו עלות קטנה שמבטיחה שהמידע שלך בטוח.
(בשכבת החינם הנתונים נמחקים בכל הפעלה מחדש — לא מתאים למערכת אמיתית.)

## עדכונים בעתיד
כשנשפר את האפליקציה, השינויים נדחפים לריפו ו-Render מעדכן **אוטומטית** —
**הנתונים שלך נשמרים** (הם על הדיסק הקבוע, לא נמחקים בעדכון).

## גיבוי
הנתונים בקובץ אחד: `/var/data/crm.db`. אפשר להוריד אותו מ-Render (Shell)
לגיבוי מדי פעם. בהמשך נוסיף כפתור גיבוי אוטומטי.
