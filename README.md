# CRM תורמים — מבנה נתונים מאוחד

מערכת CRM לניהול תורמים, הבנויה סביב **כרטיס תורם אחד ומאוחד** שמאגד מידע ממספר מקורות.

## המקורות בשלב הזה

1. **Donations Summary** — קובץ סיכום התרומות (מי תרם, כמה, דרך איזה ערוץ, ולמה).
2. **Google Contacts** — אנשי הקשר (שמות באנגלית, טלפונים, אימיילים).

> רשימת האברכים **אינה** נכללת בשלב הזה. המבנה בנוי כך שניתן יהיה לחבר אותה בהמשך כמקור נוסף.

## מה כרטיס תורם כולל

| שדה | מקור עיקרי |
|------|-----------|
| שם עברי (פרטי + משפחה) | מילוי ידני דרך קובץ ההתאמה |
| שם אנגלי (פרטי + משפחה) | Google Contacts / Donations Summary |
| שם עסק (אנגלית) | Donations Summary — לתרומות שמגיעות מהעסק |
| ערוץ/אמצעי תרומה + ייעוד | Donations Summary (רשומה לכל תרומה) |
| היסטוריית קשר (טלפון/מייל/WhatsApp) | סנכרון אוטומטי מהערוצים |
