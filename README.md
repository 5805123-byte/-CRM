# מערכת ניהול תורמים — כולל חצות

מערכת אחת מסודרת שמרכזת את **כל** מה שקשור לתורמים: מי הם, איך יוצרים איתם קשר,
מה הם תרמו ואיזה סוג תרומה, אילו שמות הם מסרו לתפילה, ובאיזה קוויטל הם נמצאים —
כדי שתוכל לעקוב, להזכיר בזמן, ולהדפיס קוויטלים בלחיצת כפתור.

> כתוב במילים פשוטות. אין צורך לקרוא הכל — התמצית כאן, והפירוט בתיקיית `docs/`.

## מה המערכת מחזיקה (4 דברים מרכזיים)

1. **תורם** — אדם או עסק: שמות (עברי/אנגלי/עסק), טלפון, מייל, וואטסאפ, כתובת,
   ותאריכים חשובים (יום הולדת, יארצייטים, תאריכים שהוא רגיל לתרום בהם).
2. **תרומה** — כל תרומה בנפרד: כמה, מתי, דרך איזה ערוץ (אתר / נדרים פלוס / בנק /
   וואטסאפ ישיר), **וסוג התרומה** (פרנס יום, פרנס המאור, שותפות יששכר-זבולון וכו').
3. **שם לתפילה** — השמות שהתורם מסר: על מי מתפללים ולמה (רפואה, זיווג, ישועה),
   ולפי גובה התרומה — באיזו **דרגת תפילה** הם נכנסים.
4. **קוויטל** — הרשימה להדפסה. אותה רשימה אפשר להפיק בכמה גרסאות: הקוויטל הכללי,
   קוויטל 101 בלבד, או רשימה מיוחדת לנסיעה למירון / כותל / קבר רחל.

בנוסף נשמרות **הקדשות והנצחות** (בניין בית הכנסת, מקווה, חדר, שולחן) בכרטיס התורם,
ותורם יוכל בהמשך **להיכנס בעצמו** עם שם משתמש/סיסמה כדי לערוך את שמות הקוויטל שלו.

## מדרגות התפילה (לפי סוג/גובה התרומה)

| דרגה | מי נכנס | מה קורה |
|------|---------|---------|
| **יששכר-זבולון** | מחזיק אברך לחודש/שנה (שטר על קלף, הסכם שותפות) | אברך מתפלל עליו בכל לילה בחצות ומקדיש לו את לימוד החצות |
| **קוויטל 101** | שותפות חודשית קבועה (101 / 180 לחודש) | 3 אברכים מזכירים בכל לילה מהקוויטל המיוחד |
| **קוויטל כללי** | תורם קבוע מתחת ל-101 | מוזכר פעם בשבוע בכותל בחצות, בקבר רחל, במירון בערב ר"ח ובעיתות רצון |
| **חד-פעמי / מזדמן** | תרם דרך האתר / נדרים פלוס / וואטסאפ / מייל | השם נמסר להתפלל בחצות פעם אחת ע"י כמה אברכים |

הפירוט המלא של כל סוגי התרומות ב-[docs/02](docs/02-donation-types-and-kvittels.md).

## מה המערכת עושה בשבילך

- **מרכזת את הנתונים** מכל המקומות שיש לך היום: האקסל, אנשי הקשר בגוגל (התווית
  "קוויטל" והתת-תוויות), רשימת הוורד של השנה, ושיחות וואטסאפ/מייל.
- **שומרת קשר**: מתי דיברת לאחרונה ועל מה, תזכורת לחזור אליהם, ימי הולדת, יארצייטים,
  ותאריכים שהם רגילים לתרום בהם.
- **קליטה אוטומטית**: תרומה חדשה באתר (עם שמות לתפילה) נכנסת למערכת לבד, עם תזכורת
  להתפלל בחצות וסיכום חודשי.
- **הדפסת קוויטל** בכמה גרסאות, לפי תווית — כולל הוספת תורמים חד-פעמיים לנסיעה מיוחדת.
- **חזרה לתורמים** (פרנס יום): לזהות מי כבר תרם בעבר ולפנות אליו שוב לקחת את הזכות.

## איך מתקדמים מכאן

ראה [docs/03 — איך מתחילים](docs/03-getting-started.md). בקצרה: אני בונה את הבסיס
מהקבצים האמיתיים שלך (אקסל + ייצוא אנשי הקשר מגוגל + רשימת הוורד), ומתחיל מהדבר
שהכי חוסך לך זמן — הפקת הקוויטל.

## מוכן לשימוש עכשיו

- **`starter/crm-donors.xlsx`** — חוברת אקסל מסודרת (עברית, מימין לשמאל) עם כל
  הגיליונות והרשימות הנפתחות. אפשר להתחיל למלא מיד. ראה גיליון "הסבר" בקובץ.
- **`tools/generate_kvittel.py`** — מפיק קוויטל מודפס מהחוברת, עם סינון לפי דרגה
  או תווית. פרטים ב-[docs/03](docs/03-getting-started.md).
